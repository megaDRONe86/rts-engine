# RTSEngine builds

Ready-to-run editor + tools. Unpack the zip anywhere and start `RTSEngine/bin/rts_editor.exe` (Windows) or `RTSEngine/bin/RTSEditor.app` (macOS). The folder also holds the engine sources at that commit, which rtsbuild uses to build games.

Published by tools/release/publish_builds.py; this branch is a single commit that is replaced on every publish (the newest 5 versions per platform are kept).
